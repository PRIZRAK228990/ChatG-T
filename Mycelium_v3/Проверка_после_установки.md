# Проверка после установки

## Первый запуск

- [ ] Игра стартует до главного меню.
- [ ] В `latest.log` нет ошибки регистрации KubeJS items.
- [ ] В JEI появился `kubejs:hematic_living_core`.
- [ ] В JEI появился `kubejs:hematic_amalgamated_heart`.
- [ ] Промежуточные `kubejs:spore_preform_*` отображаются.
- [ ] В JEI появились Bio-Forge recipes `kubejs:spore_migration/...`.
- [ ] В Decomposer отображается `kubejs:spore_migration/decomposer/amethyst_dust`.
- [ ] В Blood Altar отображаются обе кровавые операции.

## Тест машин

- [ ] Bio-Forge создаёт обычный переведённый Spore предмет.
- [ ] Bio-Forge создаёт промежуточную заготовку.
- [ ] Две заготовки собираются в конечный сложный предмет.
- [ ] Decomposer даёт гарантированный и вероятностный выход amethyst dust.
- [ ] Blood Altar расходует LP и выдаёт Hematic Living Core.
- [ ] Blood Altar расходует LP и выдаёт Hematic Amalgamated Heart.
- [ ] Все шесть предметов, требующие насыщения, не создаются без нужного hematic item.

## Только после прохождения теста

- [ ] Сделать резервную копию скриптов и мира.
- [ ] В `10_spore_biomancy_migration.js` переключить `REMOVE_ORIGINALS = true`.
- [ ] Перезапустить / выполнить полный `/reload` в тестовом мире.
- [ ] Убедиться, что обычные рецепты Spore удалены, новые остались.
- [ ] Проверить каждую категорию JEI на обходные рецепты.

## Если произошла ошибка

1. Верни `REMOVE_ORIGINALS = false`.
2. Сохрани `logs/latest.log` и `logs/kubejs/server.log`.
3. Не удаляй исходные datapack recipes из JAR.
4. Передай оба лога для исправления.
