# Mycelium KubeJS Pack — текущая версия v3

**Minecraft 1.20.1 Forge 47.4.23**  
**Spore 2.2.0j · Biomancy 2.9.8.1-alpha.0 · Blood Magic 3.3.8-50**

Начинай с этого файла. Подробности: `README_v3.md`, баланс заражённой местности: `Баланс_заражённой_местности_v3.md`.

## Самое важное изменение v3

Заражённые блоки поверхности Spore при добыче отдают обычный ванильный блок гарантированно; дополнительная биоматерия выпадает редко. Поэтому `spore:infested_dirt`, `spore:infested_stone`, `spore:infested_netherrack` и подобные блоки **не используются как предметы-входы Decomposer**. Их прямые рецепты удалены.

Вместо этого `server_scripts/31_infected_terrain_rare_drops.js` добавляет маловероятный побочный дроп `kubejs:infected_crust_fragment`, сохраняя обычный дроп без изменений. Фрагмент перерабатывается в Decomposer с малым выходом биоматериалов.

Настоящие предметные биомассные блоки Spore, имеющие собственные loot tables, по-прежнему можно перерабатывать, но с умеренным выходом и редкими побочными продуктами.

## Установка v3 поверх v2

1. Полностью закрой Minecraft.
2. Сделай резервную копию `kubejs/`.
3. Скопируй содержимое `kubejs/` из этого архива в корень сборки, объединяя папки.
4. Замени файлы с совпадающими именами версиями из v3.
5. Убедись, что добавлены `server_scripts/31_infected_terrain_rare_drops.js` и текстура `infected_crust_fragment.png`.
6. Запусти игру полностью заново: добавлен новый предмет через `startup_scripts`.
7. Проверь обычный дроп и редкий фрагмент на нескольких типах заражённых блоков.

`REMOVE_ORIGINALS` оставлен в безопасном режиме `false`. Не включай его до проверки всех новых рецептов.

## Пакет не запускался в самой игре

JavaScript синтаксис, JSON локализаций, структура девяти рецептов Decomposer и список шестнадцати обработчиков проверены статически. Внутриигровой тест Forge/KubeJS не проводился. Особенно проверь, что событие `BlockEvents.broken` срабатывает для заражённых блоков именно в твоей установленной версии KubeJS.
