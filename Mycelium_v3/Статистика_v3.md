# Статистика Mycelium KubeJS Pack v3

- Minecraft 1.20.1 Forge 47.4.23
- Spore 2.2.0j
- Biomancy 2.9.8.1-alpha.0
- Blood Magic 3.3.8-50
- Удалены прямые Decomposer-рецепты для обычных `spore:infested_*` terrain blocks.
- 16 видов заражённой местности получают дополнительный фрагмент с шансом 0,3–0,8% при разрушении игроком.
- 1 новый предмет: `kubejs:infected_crust_fragment`.
- 9 рецептов Decomposer для редкого фрагмента и предметных биомассных блоков/уплотнённой биомассы.
- Гарантированный ванильный дроп заражённой местности не изменяется.
- Редкие побочные результаты Decomposer используют `binomial` count range.

## Ограничения проверки

JS синтаксис и JSON проверены статически. Внутриигровой runtime-тест не выполнен. Нужно подтвердить работу BlockEvents.broken на Forge 1.20.1 с установленной версией KubeJS, а также вероятность дропа и фактические предметные дропы специальных блоков.
