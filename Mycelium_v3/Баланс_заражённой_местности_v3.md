# Баланс заражённой местности — v3

## Исправление принципа добычи

Заражённые блоки местности Spore (`spore:infested_dirt`, `spore:infested_stone`, `spore:infested_netherrack` и т. п.) при разрушении отдают обычный блок соответствующего типа гарантированно. Дополнительный биологический материал выпадает редко.

Следовательно, такие блоки нельзя считать гарантированными предметами `spore:infested_*` для рецептов Decomposer. В v3 все прямые Decomposer-рецепты для этих блоков удалены.

## Новая механика

При разрушении заражённой местности KubeJS с малым шансом выдаёт `kubejs:infected_crust_fragment`. Обычный дроп ванильного блока не меняется.

| Группа | Шанс фрагмента |
|---|---:|
| Dirt / Sand / Red Sand / Gravel / Clay | 0,3% |
| Stone / Deepslate / Cobblestone | 0,4% |
| Netherrack / Soul Sand | 0,5% |
| End Stone | 0,6% |
| Infested Laboratory Blocks | 0,8% |

Фрагмент перерабатывается в Decomposer:
- 1 × `kubejs:raw_mycelial_pulp` гарантированно;
- `biomancy:organic_matter` — 10% шанс;
- `biomancy:mineral_fragment` — 5% шанс.

Это побочный источник сырья, а не способ массового производства. Эти вероятности — балансировочные значения Mycelium, а не заявленные исходные шансы Spore.

## Настоящие биомассные блоки

Блоки вроде `spore:biomass_block`, `spore:sicken_biomass_block`, `spore:calcified_biomass_block`, `spore:membrane_block`, `spore:rooted_biomass`, `spore:gastric_biomass_block` и `spore:brain_remnants` имеют собственные loot tables, отдающие соответствующие предметы. Для них Decomposer-рецепты оставлены, но выход уменьшен; редкие побочные продукты используют binomial count ranges.

## Ограничения

`BlockEvents.broken` реагирует на разрушение блока игроком. Автоматическое разрушение, взрывы и сторонние способы удаления блоков необходимо проверить отдельно. Редкий фрагмент выдаётся напрямую игроку, чтобы не заменять и не портить обычный блоковый дроп.
