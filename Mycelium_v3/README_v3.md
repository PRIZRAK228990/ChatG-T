# Mycelium KubeJS Pack v3

## Ключевое исправление

Заражённая местность Spore не является гарантированным источником предметов `spore:infested_*`: при разрушении игрок получает обычный блок, а биоматериал выпадает редко. Поэтому в v3 прямые Decomposer-рецепты для `spore:infested_dirt`, `spore:infested_stone`, `spore:infested_netherrack` и остальных инфестированных вариантов удалены.

Вместо них `31_infected_terrain_rare_drops.js` с малым шансом выдаёт `kubejs:infected_crust_fragment`, не изменяя гарантированный обычный дроп блока. Фрагмент можно переработать в Decomposer с небольшим выходом сырья.

Настоящие биомассные блоки Spore, имеющие собственные предметные loot tables, остаются в Decomposer, но их выходы снижены и дополнительные ценные материалы сделаны вероятностными через Biomancy binomial count range.

## Новое

- `kubejs:infected_crust_fragment` — редкий побочный предмет заражённой местности.
- `server_scripts/31_infected_terrain_rare_drops.js` — редкие дополнительные дропы с частицами вероятностей 0,3–0,8%.
- `server_scripts/30_infected_blocks_decomposition.js` — переработка только предметов, которые действительно выпадают как отдельные блоки/предметы.
- `Баланс_заражённой_местности_v3.md` — подробные правила новой экономики.

## Установка поверх v2

1. Сделай копию папки `kubejs`.
2. Скопируй содержимое `kubejs/` из v3 в папку сборки, объединив папки.
3. Замени одноимённые файлы v2 файлами v3.
4. Добавь новый `server_scripts/31_infected_terrain_rare_drops.js` и новую текстуру предмета.
5. Полностью перезапусти Minecraft: добавлен новый предмет через startup registry.
6. Проверь разрушение каждого типа заражённого блока: обычный блок должен выпадать как прежде; фрагмент — редко.

## Важно

Вероятности 0,3–0,8% — стартовые балансировочные значения. Они не являются исходными шансами Spore. Пакет прошёл статическую проверку, но не был запущен в Minecraft. До игровых тестов не включай `REMOVE_ORIGINALS = true`.
