# Changelog v3

- Удалены 16 прямых Decomposer-рецептов для `spore:infested_*` terrain blocks: они не соответствуют реальному дропу (обычный ванильный блок гарантирован, биоматериал редкий).
- Добавлен `kubejs:infected_crust_fragment`.
- Добавлен `BlockEvents.broken` обработчик для 16 типов инфестированной местности: шанс дополнительного фрагмента 0,3–0,8%.
- Фрагмент даёт 1 сырой мицелиальный pulp в Decomposer; органическое вещество/минеральный фрагмент имеют 10%/5% chance.
- Снижены гарантированные выходы Decomposer у собственных биомассных блоков Spore; ценные побочные продукты переведены на binomial count range.
- Обычные ванильные дропы заражённых блоков не меняются.
